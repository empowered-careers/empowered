Codebase handover

A coaching and content platform for mid-to-senior tech professionals. It assesses and scores candidates, then sells them 1:1 coaching, courses, and à la carte career services.

These pages are a visual companion to the markdown in docs/handover/, which is the source of truth. Every section links back to it.

Five things to know before touching anything

1. Revenue is à la carte only

There are no subscriptions. Entitlement is a row in enrollments, written by the Stripe webhook — never profiles.plan. Never add a plan-based gate.

2. Dormant ≠ deleted

The job board, matching, employer portal, and subscription code are kept deliberately. They're unlinked from candidate nav, not removed. Don't build on them; don't delete them.

3. RLS is the authorization model

And a policy-blocked write returns success-shaped empty data, not an error. If a write "succeeds" but no row appears, suspect RLS before anything else.

4. The money path has never completed end to end unverified

payments and enrollments were both 0 rows at last audit. Everything downstream — the purchase gate, entitlement checks, JD quota, coaching access — is built on it. Verify it first.

5. There are no automated tests

Ten assert-based .check.ts files exist and CI runs none of them. Verification is type-check, lint, LLM evals, and manual smoke tests.

The pivot

The platform launched job-board-first: a curated board of exclusive roles gated by a subscription tier, with matching, an employer portal, and placement commissions. In August 2026 it pivoted to coaching-first.

Rather than rip the old product out, the pivot unlinked it. Schema stays, routes stay, admin surfaces stay — nothing in candidate navigation points at it. That's why roughly half the codebase serves a product that's no longer sold.

Three rules that override anything older in docs/:

1. Dormant ≠ deleted.  ·  2. No subscriptions — entitlements route through enrollments.  ·  3. Intake stays mandatory — the resume-upload gate before dashboard access stays, because building the candidate list is the point.
